# 📘 Proyecto: Red Social

## 📌 Introducción
Este proyecto consiste en una **red social sencilla** en la que los usuarios pueden registrarse, iniciar sesión y compartir publicaciones.  
La aplicación se conecta con una **API** previamente desarrollada y ofrece todas las funciones básicas de una red social moderna.

El objetivo es mostrar de manera práctica cómo se integran un **frontend (interfaz visual)** con un **backend (servidor y base de datos)**, garantizando una experiencia completa para el usuario.

---

## 🚀 Funcionalidades principales
El sistema incluye las siguientes características:

- **Registro de usuarios:** crear una cuenta nueva.  
- **Login de usuarios:** acceder a la aplicación con un correo y contraseña.  
- **Posts (publicaciones):**
  - Ver publicaciones de la comunidad.
  - Crear nuevas publicaciones.
  - Editar y eliminar publicaciones propias.
- **Interacciones:**
  - Dar o quitar "Like" en publicaciones.
  - Comentar en publicaciones.  
- **Perfil personal:**
  - Ver los datos personales del usuario registrado.
  - Ver todas las publicaciones creadas por dicho usuario.  
- **Buscador:** permite buscar otros usuarios o publicaciones.  

---

## 🛠️ Requisitos técnicos cumplidos
- Uso de **ramas en Git**:
  - `main` o `master` → versión final del proyecto.  
  - `develop` → rama de desarrollo.  
- **Frontend desarrollado con React**, utilizando:
  - **React Router** (para la navegación entre páginas).  
  - **Redux** (para la gestión del estado de la aplicación).  
  - **SASS** (para los estilos y diseño visual).  
- **Diseño cuidado y adaptado a usuarios finales.**  

---

## 🧩 Componentes mínimos desarrollados
- **Register:** formulario de registro.  
- **Login:** formulario de inicio de sesión.  
- **Home:** página de inicio de la red social.  
- **Posts:** listado de publicaciones.  
- **Post:** representación de una publicación.  
- **AddPost:** formulario para crear un nuevo post.  
- **PostDetail:** vista detallada de una publicación con comentarios.  
- **AddComment:** formulario para añadir comentarios.  
- **Profile:** vista con los datos y publicaciones del usuario logeado.  
- **Header & Footer:** cabecera y pie de página de la aplicación.  

---

## 📂 Estructura de rutas principales
- `/home` → Página principal.  
- `/login` → Inicio de sesión.  
- `/register` → Registro de usuarios.  
- `/profile` → Perfil del usuario registrado.
